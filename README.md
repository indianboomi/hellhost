# Hell Host

Responsive dark hosting website for **Hell Host**, designed to work directly in VS Code.

## Pages
- Home — index.html
- About — about.html
- Contact — contact.html
- Login — login.html
- Dashboard — dashboard.html

## Run in VS Code
Open the repository folder in VS Code and start it with **Live Server**, or open index.html directly in your browser.

## Authentication note
The included login/logout flow is a front-end demo using localStorage. It is not secure production authentication. For real Google, GitHub and Discord login, connect an OAuth-capable backend/auth provider such as Supabase or your own server.
